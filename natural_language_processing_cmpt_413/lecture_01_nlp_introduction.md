# NLP introduction and course setup

NLP turns ambiguous, evolving language into useful predictions and actions through representation, composition, and learning.

## The central problem

Language is ambiguous, context-dependent, and constantly changing. NLP systems translate, classify, answer questions, generate text, or act on instructions. Rare words and combinations create a long tail, so even large datasets leave gaps.

A useful model needs three things:

1. **Representation:** turn words or sentences into a computational form.
2. **Composition:** combine units while preserving information relevant to the task.
3. **Prediction:** map the representation to a label, output sequence, or action.

## Course expectations

Expected background includes Python, calculus, linear algebra, probability, and machine learning. Lectures focus on concepts; tools require independent practice. Course expectations include group programming work, individual conceptual work, and understanding and explaining LLM-assisted submissions.
